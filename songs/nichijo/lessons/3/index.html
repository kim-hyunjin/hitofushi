뜻할당량 이하인가 이상인가, 일상은 오늘도 평가받아

문법

GRAMMAR · 입문

〜か〜か

명사 / 보통형 + か + 명사 / 보통형 + か

두 가지 가능성이나 선택지를 나란히 제시합니다.

의문 조사 か를 두 항목 뒤에 붙이면 ‘~인지 ~인지’라는 선택 구조가 됩니다. 답을 묻기보다 상반된 기준을 함께 보여 줄 때도 사용합니다.

후렴의 以下か以上か, 変わりないか元気か가 같은 리듬을 만듭니다.

예문

行くか行かないか決める。
갈지 안 갈지 정한다.
上か下か分からない。
위인지 아래인지 모르겠다.

GRAMMAR · 초급

수동형

동사 수동형 〜(ら)れる

다른 사람이나 상황으로부터 어떤 작용을 받음을 나타냅니다.

5단 동사는 끝소리를 あ단으로 바꾸고 れる, 1단 동사는 る를 빼고 られる를 붙입니다. 원치 않는 영향을 받았다는 뉘앙스도 자주 생깁니다.

計られる는 기준에 의해 평가받는 상태, 言われる는 말을 듣는 상황입니다.

예문

スーツでもスウェットでもそれは同おなじみたいだ

ひらがなすーつ でも すうぇっと でも それ は おなじ みたいだ

발음 도움스으츠데모 스웻토데모 소레와 오나지미타이다

뜻정장을 입어도 운동복을 입어도 그건 똑같은 것 같아

문법

GRAMMAR · 입문

〜でも〜でも

명사 + でも + 명사 + でも

서로 다른 경우를 들어 어느 쪽이든 같다고 말합니다.

でも를 반복하면 ‘~이든 ~이든’, ‘~이어도 ~이어도’라는 뜻이 됩니다. 조건이 달라져도 뒤의 판단은 바뀌지 않음을 강조합니다.

가사에서는 옷차림이나 하루의 좋고 나쁨과 무관하게 같은 일상이 이어집니다.

예문

雨でも雪でも行く。
비가 와도 눈이 와도 간다.
朝でも夜でも大丈夫だ。
아침이어도 밤이어도 괜찮다.

GRAMMAR · 입문

〜みたいだ

보통형 / 명사 + みたいだ

보이는 근거나 느낌을 바탕으로 ‘~인 것 같다’고 추측합니다.

〜みたいだ는 대화에서 자주 쓰는 부드러운 추측 표현입니다. 직접 확인한 사실이라기보다 화자가 보고 느낀 인상을 전달합니다.

이 곡에서는 자신의 상태와 반복되는 일상을 조심스럽게 판단하는 말투를 만듭니다.

예문

雨が降るみたいだ。
비가 올 것 같다.
彼は元気みたいだ。
그는 건강한 것 같다.

〜みたいだ는 대화에서 자주 쓰는 부드러운 추측 표현입니다. 직접 확인한 사실이라기보다 화자가 보고 느낀 인상을 전달합니다.

이 곡에서는 자신의 상태와 반복되는 일상을 조심스럽게 판단하는 말투를 만듭니다.

예문

雨が降るみたいだ。
비가 올 것 같다.
彼は元気みたいだ。
그는 건강한 것 같다.
